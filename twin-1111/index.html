ג. ב-HeyGen

HeyGen מייצרים בסוף סרטון הדגמה באנגלית לרוחב ("Meet your avatar"). הוא לא הסרטון שלכם, אפשר לדלג עליו.

אין צורך בשום דבר טכני. 10 דקות, וזה הסרטון הראשון שלכם.

4המנגנון (דרכים 2–3)

Claude Code הוא קלוד שעובד בתוך תיקייה במחשב שלכם, ויכול להפעיל בשבילכם כלים אחרים. הוא נמצא באפליקציית Claude, בלשונית Code.

מפתח API הוא קוד שנותנים לקלוד כדי שיוכל להפעיל את ElevenLabs ואת HeyGen בשמכם. כמו מפתח לדירה שנותנים לשכנה שמשקה את העציצים. שומרים אותו כמו כרטיס אשראי.

הדרך המהירה: התיקייה המוכנה

הקמה, עם התיקייה המוכנהבוא נתחיל

איפה מוצאים את המפתחות? ב-ElevenLabs: Developers ← API Keys. ב-HeyGen: בהגדרות, בחלק של ה-API. המפתח מוצג פעם אחת כשיוצרים אותו, אז מעתיקים אותו מיד. אין יתרת API ב-HeyGen? משאירים את השורה שלו ריקה, וקלוד יעבוד בדרך 2.

או: בונים בעצמכם עם פרומפט אחד

בונים את המנגנון בעצמכם (במקום התיקייה)אני רוצה ליצור סרטונים עם אווטאר שמדבר בקול שלי. יש לי ב-HeyGen תאום דיגיטלי, וב-ElevenLabs קול משובט. תבנה איתי בתיקייה הזו מנגנון שבו אני רק כותבת על מה הסרטון: אתה כותב תסריט קצר בסגנון שלי ומחכה לאישור שלי, מייצר את הקול ואת הסרטון, ושומר לי את הסרטון המוכן בתיקייה. תדריך אותי איפה לשמור את המפתחות כך שאתה לא רואה אותם, ותעצור בכל שלב שדורש ממני פעולה. בסוף, תשמור את התהליך כסקיל, כדי שבפעם הבאה יספיק לי לכתוב "סרטון על…".
